# Barbara Felizola — The Fighter & The Baker

Atleta de Jiu Jitsu de élite (Campeona Europea 2026, World Master 2024) y repostería artesanal saludable. Sitio dual: Athlete / Bakery con selector de modo, logros IBJJF, productos y CTAs por WhatsApp.

- **Stack:** Next.js 15, React 19, Tailwind v4, DaisyUI v5, Supabase, Framer Motion, Lucide React
- **Dominio:** felizola-ecommerce.vercel.app
