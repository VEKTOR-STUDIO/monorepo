# Project Metadata & Favicon

Adapt all metadata, SEO, favicons and domain references to the **current project**. The app is assumed to be deployed at **`<project-slug>.vercel.app`** (e.g. `serpa-agricola.vercel.app`). Use the project’s `config.js` as the single source of truth for name, description and domain.

## 1. Config (source of truth)

- **File**: `config.js`
- Set: `appName`, `appDescription`, `domainName`, `siteUrl`, `colors.main`, `colors.theme`, `business` (address, phone, email).
- **Domain**: Use `domainName` without `https://` (e.g. `serpa-agricola.vercel.app`). `siteUrl` in production must be `https://<domainName>`.

## 2. SEO & metadata

- **Root metadata**: `app/layout.js` — `getSEOTags({ title, description, canonicalUrlRelative: "/" })`. Use project name and tagline.
- **libs/seo.js**:
  - Default `title` / `description` / `keywords`: from `config.appName` and project context (no template/client names).
  - `metadataBase`, `openGraph.url`, `twitter`: use `https://${config.domainName}/`.
  - `applicationName`, `authors`, `creator`: `config.appName`.
  - `renderSchemaTags()`: `LocalBusiness` (or appropriate type) with `config.appName`, `config.appDescription`, `config.business`, `config.domainName`.
- **Per-page**: `app/privacy-policy/page.js`, `app/tos/page.js`, `app/signin/layout.js`, `app/blog/page.js` — use `getSEOTags()` with titles/descriptions that reference `config.appName`; replace any hardcoded template name or old domain in the visible text and in comments.

## 3. Favicon & icons

All icons must reflect the **current project** (e.g. initial letter “S” for Serpa), not the template (e.g. “F”). Use the project’s primary color and dark background from config/theme.

- **app/icon.js** (favicon 64×64): Letter or mark of the project; colors from theme (e.g. primary `#E85D00`, background `#0f1419`).
- **app/apple-icon.js** (180×180): Same letter/mark and colors.
- **app/twitter-image.js** (1200×628): Same branding; optional subtitle with `config.appName` and tagline.
- **scripts/generate-favicon.mjs**: Update comment and constants to current project name and colors; generate letter/mark (e.g. “S”) in project primary on dark background. Run `node scripts/generate-favicon.mjs` to refresh `public/favicon.svg` and variants.

## 4. Domain and URLs

- **Always .vercel.app**: Default production URL is `https://<project-slug>.vercel.app`. No trailing slash in `domainName`.
- **next-sitemap.config.js**: `siteUrl: process.env.SITE_URL || "https://<project-slug>.vercel.app"` (match `config.domainName`).
- **public/sitemap-*.xml**: Generated by build; if hand-edited or stale, replace old domain with `https://<config.domainName>`.
- **Legal and comments**: In privacy, TOS, README, and doc comments, replace any old domain or template name with `config.appName` and `config.domainName` (or the literal `https://<project>.vercel.app`).

## 5. Credit / “Alessandrovaru”

- Keep the “Alessandrovaru” link (e.g. in Footer) with **Microgramma** font: `style={{ fontFamily: "var(--microgramma-font)", textTransform: "uppercase", letterSpacing: "0.1em" }}`.
- Link target remains `https://alessandrovaru.com` unless the user requests a change.
