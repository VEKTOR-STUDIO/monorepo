# Distinctive Frontend Design

Guides creation of production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with strong attention to aesthetic details and creative choices.

## Quick Start

When the user asks for a component, page, app, or interface:

1. Understand purpose, audience, and constraints
2. Commit to a clear aesthetic direction (minimal, maximalist, retro, luxury, brutalist, etc.)
3. Implement working code that is production-grade, visually striking, and cohesive

## Design Thinking

Before coding:

- **Purpose**: What problem does this interface solve? Who uses it?
- **Tone**: Pick a clear direction: brutally minimal, maximalist chaos, retro-futuristic, organic, luxury/refined, playful, editorial, brutalist/raw, art deco, soft/pastel, industrial, etc. Execute that direction with precision.
- **Constraints**: Framework, performance, accessibility.
- **Differentiation**: What makes it memorable?

**CRITICAL**: Bold maximalism and refined minimalism both work. The key is intentionality, not intensity.

## Frontend Aesthetics Guidelines

- **Typography**: Distinctive, characterful fonts. Avoid Arial, Inter, Roboto. Pair a display font with a refined body font.
- **Color & Theme**: Cohesive palette. CSS variables. Dominant colors with sharp accents.
- **Motion**: Animations and micro-interactions. CSS-first; Motion library for React when available. Staggered reveals, scroll and hover surprises.
- **Spatial Composition**: Asymmetry, overlap, diagonal flow, grid-breaking elements, generous whitespace or controlled density.
- **Backgrounds & Details**: Depth and atmosphere. Gradient meshes, noise, geometric patterns, layered transparencies, shadows, grain overlays. Avoid flat solid fills.

NEVER use overused fonts (Inter, Roboto, Arial, system fonts), cliched schemes (e.g. purple gradients on white), or cookie-cutter layouts. Vary themes, fonts, and aesthetics. Do not converge on common choices (e.g. Space Grotesk) across generations.

Match implementation complexity to the vision: maximalist needs elaborate code and effects; minimalist needs restraint, precision, and subtle detail.
